
- Python
	- nice and short
	- indentation, line breaks
	- dynamic typing
	- code can go anywhere really
	- \# comment, """multiline comment"""
	- functions (def)
	- for i in range(n)
- Java
	- long and ugly
	- braces, semicolons
	- static typing
	- code in methods, methods in classes
	- // comment, /\* multiline comment \*/
	- functions
	- for (int i = 0; i < n; i++)
	- extremely verbose
