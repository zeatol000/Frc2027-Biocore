I would like to start this with a disclaimer: Functional Programming can be quite difficult and confusing. Normally, I wouldn't even put it in a "simple Java quickstart" for how difficult it can be. But unfortunately, functional programming is very powerful and is used a lot in FRC programming.

If you've taken Pre-Calculus before, it would be a good idea to think of functional programming like function composing. If you haven't taken Pre-Calculus before, take notes I guess.


Disclaimer out of the way, **Functional Programming** is a programming "paradigm" similar to object oriented programming. While object oriented programming focuses on objects and data, functional programming focuses on the functions and transformations.
